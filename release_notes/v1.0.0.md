Перша версія. Замінює ручну процедуру з cmd (`yt-dlp -F`, пошук ID очима, `-f "137+251"`).

- Вставили посилання — аналіз запускається сам; `&list=`, `&t=`, `?si=` прибираються
- **Якість** — за замовчуванням 1080p H.264 (або найближча нижча); режим «Лише звук» (m4a / mp3)
- **Звукова доріжка** — українська за замовчуванням, навіть якщо це ШІ-дубляж YouTube; оригінал можна додати другою доріжкою, обидві підписані мовою
- **Субтитри** — від автора, автопереклад українською, мовою оригіналу; вшити у відео чи окремий `.srt`. Без української доріжки українські субтитри вмикаються самі
- **Формат** — mp4 / mkv
- Черга з прогресом, швидкістю, часом до кінця й скасуванням
