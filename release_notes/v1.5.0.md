Кілька посилань — таблицею, і все вміщається навіть у невелике вікно.

**Список посилань**
- Вставлений список більше не зливається в поле одним довгим рядком: поле очищається, а в картці пакета видно всі ролики таблицею — №, код товару, ролик (назва або коротке `youtu.be/…`) і примітка: «той самий ролик, що в рядку 2 — буде копія», «уже в черзі — пропуститься», «поза "Перші N"».
- **✕** у рядку (або Delete для виділених) прибирає ролик із пакета.
- Під полем видно, скільки посилань знайдено й скільки рядків без посилання пропущено (наприклад, шапка таблиці).

**Вікно**
- Усе вміщається й на невеликому вікні (880×660): раніше кнопка «Завантажити» пакета могла опинитися за нижнім краєм.
- Поки відкрита картка відео чи пакета, список завантажень згортається до заголовка з лічильниками.
- Тека для збереження — одна, під полем посилання; клік по шляху відкриває теку.
- Картку відео можна закрити кнопкою **Скасувати**, нічого не додаючи.
- У списку завантажень угорі те, що качається зараз, далі черга по порядку, внизу завершені. Рядки в черзі коротші.
- Кнопки над списком більше не налазять на «Завершено: N · ⏱».
- Перемикач «Вшити / Окремий файл» видно лише тоді, коли обрано субтитри.
